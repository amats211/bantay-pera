Bantay Pera - phone app files

Upload ALL files in this folder to a GitHub repo (e.g. "bantay-pera"),
then Settings > Pages > Deploy from branch > main > / (root) > Save.
Open https://<your-username>.github.io/bantay-pera on your Android phone in Chrome,
then menu (three dots) > Add to Home screen > Install.

Your data stays only on your phone. Use Settings > Download backup file regularly.
